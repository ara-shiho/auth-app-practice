auth-app-practice

## 概要
COACHTECH 教材 Tutorial 10-1 「承認機能 ハンズオン演習」で作成した成果物です。Laravel Fortifyを使ったログイン・ログアウト・ユーザー登録機能と認証が必要なダッシュボードを作成。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Laravel Fortify（認証）
- MySQL

## 学んだこと
- Fortifyの設定方法
- ログイン・ログアウト機能の仕組み、作成方法
- 認証済みユーザーの取得、ルートの作成方法。
